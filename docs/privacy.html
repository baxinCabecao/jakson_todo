Política de Privacidade - Jakson Todo

Última atualização: 22 de Agosto de 2026

1. Armazenamento Local

O Jakson Todo é um aplicativo desktop. Todas as suas tarefas, configurações e dados são salvos exclusivamente de forma local no seu computador em um banco de dados SQLite.

2. Uso do Google Drive e Escopo appdata

Ao ativar o backup na nuvem, o aplicativo solicita apenas o escopo https://www.googleapis.com/auth/drive.appdata.

Esse escopo dá acesso exclusivo e isolado à pasta oculta de dados do aplicativo no Google Drive (Application Data Folder). O aplicativo não tem acesso a nenhum outro arquivo ou documento pessoal do seu Google Drive.

3. Compartilhamento de Dados

Nenhum dado é coletado, vendido, rastreado ou compartilhado com terceiros.

4. Contato

Para dúvidas, consulte o repositório oficial do projeto no GitHub.
