# Privacy Policy / Política de Privacidade - Jakson Todo

*Last updated / Última atualização: 2026-08-22*

## 1. Overview / Visão Geral
**Jakson Todo** is an open-source desktop personal task management application. We respect your privacy and are committed to protecting your personal data.

O **Jakson Todo** é um aplicativo desktop open-source para gerenciamento de tarefas pessoais. Respeitamos sua privacidade e temos o compromisso de proteger seus dados.

---

## 2. Data Collection & Storage / Coleta e Armazenamento de Dados
- **Local Storage / Armazenamento Local**: All your tasks, subtasks, categories, and settings are stored locally on your device in an SQLite database.
- **No Third-Party Analytics / Sem Rastreamento**: The application does not collect analytics, telemetry, or personal tracking data.
- **Cloud Backup / Backup em Nuvem**: When you explicitly connect Google Drive or Microsoft OneDrive, the application only uploads your local database file directly to your private application storage folder (`appDataFolder`).

---

## 3. Google Drive Data & Permissions / Uso dos Dados do Google Drive
- **Scoped Access / Escopo Restrito**: The application requests only the `https://www.googleapis.com/auth/drive.appdata` scope.
- **Isolation / Isolamento**: This scope grants access exclusively to a hidden, isolated folder created specifically for Jakson Todo. The application cannot view, modify, or delete any of your other Google Drive files or documents.
- **No Server Transfer / Sem Servidores Intermediários**: Communication occurs directly between your local desktop application and Google APIs. Your authentication tokens and backups are never sent to third-party servers.

---

## 4. Contact / Contato
If you have any questions regarding this Privacy Policy, please open an issue on the official GitHub repository.
Para dúvidas ou suporte, abra uma issue no repositório oficial do GitHub.
